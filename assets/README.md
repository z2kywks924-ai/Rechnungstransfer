# Logo

- `logo.png`: NHZ-Systems-Logo, erscheint im Kopf der Plugin-Seite (96 px hoch).
  Alternativ `logo.svg` oder `logo.jpg` (SVG hat Vorrang).
- `menu-icon.png`: Bildmarke als Symbol im Admin-Menü (40×40, transparent).
  Ein einfarbiges `menu-icon.svg` hätte Vorrang.
- `icon.ico`: NHZ-Symbol (16–256 px), Browser-Tab-Symbol auf der Plugin-Seite.
- `icon-256x256.png`: dasselbe Symbol als PNG.
